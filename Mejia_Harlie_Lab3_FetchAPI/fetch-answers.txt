1. What are the main differences between XMLHttpRequest and Fetch API?

XMLHttpRequest is an older way of making HTTP requests using JavaScript. Fetch API is a newer method that uses Promises and provides a simpler way to handle requests and responses.

2. Why is the Fetch API considered more modern and readable?

The Fetch API is considered more modern and readable because its syntax is simpler and it uses Promises. It makes asynchronous code easier to understand and manage.

3. What is the purpose of the .then() and .catch() methods in Fetch?

The .then() method is used to handle the successful result of a Fetch request. The .catch() method is used to handle errors that may occur during the request.

4. What happens when you send a POST request to the placeholder API?

The POST request sends new data to the placeholder API. The API simulates creating a new post and returns a response with a new post ID, which is 101 in this exercise.
