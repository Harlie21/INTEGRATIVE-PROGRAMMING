1. readyState tells the current stage of the XMLHttpRequest, while status tells the HTTP response status from the server. For example, readyState 4 means the request is complete, while status 200 means the request was successful.
2. The request can be made asynchronous by setting the third parameter of xhr.open() to true. For example: xhr.open("GET", "https://jsonplaceholder.typicode.com/posts/1", true).
3. Asynchronous communication is recommended because it allows the web page to continue working while waiting for the server response. This makes the application faster, smoother, and more responsive for users.
